GET
/api/v1/reports/{company_id}/{report_id}/coverage
Get Report Coverage


Return every indicator in the report's framework scope, tagged FOUND / PARTIAL / NOT_DISCLOSED.

NOT_DISCLOSED rows are derived on the fly via LEFT JOIN — they are not persisted in esg_evidence. An indicator that appears in multiple documents shows the highest-confidence evidence as its primary record; pass include_duplicates=true to see the rest under additional_evidence.

Each FOUND/PARTIAL row carries a provenance block (verbatim_quote, narrative_summary, context_snippet, raw_value, raw_unit, raw_confidence, raw_source_page) lifted from esg_evidence.raw_evidence, plus the document filename and the unmodified raw_evidence + normalization_warnings for power-user / debugging needs. include_page_text=true additionally inlines extracted_content.body_text for each (document_id, source_page) — useful to render the originating page in the UI, but the response can grow several MB on a large report so it's opt-in.
