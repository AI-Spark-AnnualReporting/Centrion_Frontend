GET
/api/v1/lookups/scopes
List Scopes


Combined catalogue of every framework option the user can pick when generating a report — both scope_type=global (GRI / IFRS-S1 / IFRS-S2) and scope_type=regional (each regulator with at least one linked indicator).

Each row carries an indicator_count so the frontend can show e.g. "GRI Standards (128 indicators)" or "SAMA (42 indicators)" in a single picker.

Returns: { "universal": [{code, label, indicator_count}], "regional": [{regulator_id, code, label, country_id, country_code, country_name, primary_frameworks, indicator_count}], "totals": {universal_options, regional_options} }

Filtering:

Universal: any framework with >= 1 active indicator.
Regional: any regulator with is_active=TRUE AND at least one active regulator_metrics row pointing at a real framework_indicator_id. Empty regulators are hidden — they wouldn't narrow the harvester to anything useful.
